# Mock Vulnerable Repository (Lucid-CI Testbench)

An intentional polyglot testbed repository for verifying Abstract Syntax Tree (AST) taint tracking, ephemeral sandbox detonation, and automated AI remediation pipelines in **[Lucid-CI](https://github.com/kleeeoss/project-lucid)**.

## Repository Structure

```text
├── server/                    # Node.js & TypeScript Express service
│   ├── routes/
│   │   ├── vulnerable_routes.js # SQLi, Command Injection, Path Traversal, Secrets
│   │   └── safe_routes.js       # Sanitized counterpart routes (Zero False-Positives)
│   └── services/
│       └── auth_service.ts      # TypeScript service with taint flow
├── api/                       # Python Flask & Django backend
│   ├── app.py                 # Flask routes with SQLi, Command Injection, Path Traversal
│   ├── safe_service.py        # Sanitized Python service (shlex.quote, parameterized)
│   └── orm_queries.py         # Django ORM patterns
└── tests/fixtures/            # Edge cases, f-strings, template literals, and malformed syntax
```

## How to Test in Lucid-CI

1. Open your Lucid-CI Web Dashboard (e.g., `http://localhost:3000` or the AWS EC2 showcase URL).
2. Click **"Quick Scan Public Repo"** on the dashboard header (or navigate to **`/repositories`** $\to$ **"Add Repository"**).
3. Paste this repository URL:
   ```text
   https://github.com/kleeeoss/mock-vulnerable-repo
   ```
4. Click **"Run Security Scan"**.
5. Watch Lucid-CI clone the repository, execute Tree-sitter AST taint tracking, and redirect to the **Scan Workbench** displaying:
   - Interactive React Flow AST Taint Graph (`SOURCE` $\to$ `TAINT` $\to$ `SINK`)
   - Monospaced line-by-line diff patches generated by Google Cloud Vertex AI
   - Telemetry ribbons and severity badges.
